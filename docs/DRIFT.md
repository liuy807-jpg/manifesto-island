# Drift（漂流）说明

第二章已经接在小岛的小船边上。先读完第七条宣言，点「继续 · 漂流」，再留下一幅画面。纸船会把它带到海上，变成群岛里的一座小岛；随后会漂来别人写的一句。第三条「上岸」（AR）这一版只做了预告，还没有做。

## 会存到哪里

公开的句子存在 [MantleDB](https://mantledb.sh) 的一个已占用的命名空间里。不需要参观者登录，也不需要你再注册账号。网站是静态的，所以写入用的密钥会打进前端包里——它只能算「公开的写入口」，不是管理员密码。任何人只要读到打包后的 JS，理论上也能写入或改隐藏标记。前端还有字数限制（80 字）、每个设备大约 6 小时只能寄一次、以及简单的脏话 / 网址过滤。

限制（免费方案，以 MantleDB 现行说明为准）：

- 单个条目最大 64KB。我们把所有小岛放在同一个条目里，大约能安全放下最新 200 条。
- 每天大约 10,000 次请求，超过会返回 429。
- 文档里写过：被占用的命名空间如果长期没有活动，可能会在约 90 天后被清理。作品集长期存放，请以后迁到你自己的 Supabase / Firebase / 自己的小后端。
- 两个人几乎同时寄出时，有极小概率互相覆盖；目前用 PATCH 合并来降低这个机会。

如果远程接口打不开，网站会退回到这台设备的 localStorage，并在纸条上说明：这一次先只存在这台设备上。

命名空间和写入密钥写在 `src/drift/config.js`。管理员口令只写在项目根目录的 `PRIVATE_drift.txt`（不要提交，也不要放进作品集说明）。

## 怎样隐藏一条不合适的句子

1. 打开 `PRIVATE_drift.txt`，复制 `ADMIN_TOKEN`。
2. 用带参数的地址打开网站：`https://你的域名/?admin=口令`
3. 点海上那座小岛，纸条上会出现「隐藏」。隐藏后，普通访客就看不到它了。需要的话可以再点「取消隐藏」。
4. 看完请从地址栏去掉 `?admin=`，不要把带口令的链接发给别人或放进作品集。

种子里的六句标成「Yuting · 宣言」，不是虚构的参观者。请尽量不要隐藏它们，除非你改了宣言本身。

展览当天如果要多试几次，用带 `?admin=` 的地址可以绕过「每台设备 6 小时一次」的限制。
